Abstract

This project introduces an RFID-based smart attendance system that replaces manual methods with contactless automation. The system improves efficiency, accuracy, and security using RFID tags and microcontroller integration.

Objectives

  • Automate student attendance using RFID.
  • Display attendance status on LCD.
  • Reduce proxy and manual errors.

Introduction

RFID technology allows wireless identification of students using cards. This system logs attendance when a valid RFID tag is scanned and displays it on an LCD. The project provides a scalable solution for institutions.

Proposed Methodology

Each student has an RFID card. When scanned, the RFID reader reads the tag UID and sends it to Arduino. If matched with a registered ID, the LCD shows "Attendance Marked". The buzzer alerts for invalid tags.

Hardware and Software

  • Arduino Uno
  • RFID RC522 Module
  • 16x2 LCD Display
  • Buzzer
  • Breadboard & Jumper Wires
  • Arduino IDE

Conclusion

This project demonstrates an efficient and contactless method of attendance monitoring. The system reduces manual workload, ensures accuracy, and can be deployed across schools and colleges.

Implementation & Results

The setup was implemented and successfully tested in a prototype environment. RFID tags were recognized, attendance marked and displayed correctly. The system reduced time and improved accuracy.
