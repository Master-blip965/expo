Abstract

EchoFinder is a smart tracking system that uses RFID and ultrasonic sensing to help users locate lost items. Tagged items emit ultrasonic signals when triggered via a mobile app, allowing accurate distance and direction detection. It outperforms Bluetooth trackers in both precision and energy efficiency, especially indoors.

Objectives

  • Integrate RFID and ultrasonic tech for accurate, low-power item tracking.
  • Build a mobile app for real-time search and distance feedback
  • Improve indoor tracking beyond Bluetooth limitations

Introduction

EchoFinder is a smart tracking solution that helps users locate lost items with high accuracy. By combining RFID and ultrasonic sensing, it outperforms traditional Bluetooth trackers—especially in indoor or cluttered environments. Controlled via a mobile app, it offers a fast and efficient way to find tagged belongings

Proposed Methodology

EchoFinder tags items with RFID and ultrasonic modules. When a user searches via the app, the system identifies the item using RFID, then calculates distance and direction through ultrasonic pulses, guiding the user to the item.

Hardware and Software

  • Arduino Uno
  • RFID RC522 Module
  • 16x2 LCD Display
  • Buzzer
  • Breadboard & Jumper Wires
  • Arduino IDE

Conclusion

EchoFinder provides a precise and energy-efficient way to track lost items indoors. By combining RFID and ultrasonic technologies, it improves accuracy and reliability over traditional Bluetooth-based systems, offering a smart and user-friendly tracking solution.

Implementation & Results

The EchoFinder system was tested with RFID and ultrasonic components, successfully detecting tags and measuring distance and direction. While the mobile app is still under development, initial tests showed improved accuracy and reduced search times.
